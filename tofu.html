Did the model forget? Leak rate after unlearning

A model trained to forget some facts (TOFU, "unlearning") may still give them away when it is sampled. Scholten et al. (arXiv:2410.03523) measure this by drawing 1,024 answers per question and having a judge check each one for the forgotten fact; the share that leaks is the leak rate. Here both sides run the evaluation's first batch: 8 forget-set questions at once, 1,024 answers each, all judged.

Setup

How this was measured

vLLM
The evaluation baseline's batch: one generate() over 8 prompts, unchanged, then its own judge loop. Wrappers in vLLM's output processor note each engine step's time and which rows got a token; the judge loop notes the time after each answer.
Banyan
The algorithm is the evaluation's application on the user API. The measurement notes the time each node of the tree was made (the runtime's own new-node callback, no change to the system), and its @judge notes the time after each verdict.
the cost of noting
Each side ran the timed part twice, with and without the notes: vLLM ; Banyan . The replay uses the runs with notes.
Banyan is a research system under development.
