Truncated decoding trees

Distinct Leaf Enumeration (arXiv:2604.20500) explores a question's decoding tree instead of sampling it: from the greedy answer it opens, in order of path probability, the alternative tokens above a threshold, follows each greedily to the end, and stops after 32 distinct answers (leaves); the first 8 vote. Here both sides run it on one GSM8K question with Qwen2.5-0.5B-Instruct.

Both runs, on one clock

Press Play to replay the two measured runs in step. Both sides build a tree: left, the paper's algorithm on vLLM, which sends each branch to the engine as a new request, 4 branches at a time; right, the same algorithm on Banyan, which runs the branches inside one tree and fills the rest of its batch with branches it computes ahead. Below, the leaves each side has found.

The prompt is at the centre of each circle and the distance from it is the token position. A line's width is the number of leaves below it. Both are ordered around the circle by text, so outputs that begin the same way are next to each other. Hover the chart to move the clock.

Both trees are drawn from the runs' records. vLLM's tree is the union of its requests (prefix and output); branches stopped early because they repeated a sibling. Banyan computed tree nodes ahead that the search never used; they are not drawn.

Setup

How this was measured

vLLM
The evaluation's rewrite of the paper's algorithm (the authors' code is not released), unchanged. Its request function keeps each request's prefix and output; a wrapper in vLLM's output processor notes each engine step's time and which requests got a token; a wrapper on the leaf class notes when a leaf is made.
Banyan
The algorithm is the evaluation's application on the user API. The measurement notes the time each node of the tree was made (the runtime's own new-node callback, no change to the system), and its @judge notes when a leaf is counted. A node computed ahead is noted when the search claims it.
the cost of noting
Each side ran the timed part twice, with and without the notes: vLLM ; Banyan . The replay uses the runs with notes.
Banyan is a research system under development.
